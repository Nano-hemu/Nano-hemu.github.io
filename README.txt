HEMANT KUMAR JAISWAL - 4 PAGE PERSONAL WEBSITE

PAGES
index.html      Home / capabilities / potential
about.html      Summary / education / professional journey / social links
projects.html   Portfolio with category filters
blogs.html      Searchable reports and write-up library

LOCAL PREVIEW
1. Extract the ZIP file.
2. Keep all files and the assets folder together.
3. Double-click index.html.
4. Use the navigation to move between all four pages.

GOOGLE SCHOLAR
A verified personal Google Scholar profile URL was not found during this build.
The current link opens a Google Scholar author search for "Hemant Kumar Jaiswal".
When your personal Scholar profile exists, replace the Google Scholar href in about.html.

ADDING A REPORT OR BLOG
Duplicate one <article class="blog"> ... </article> block in blogs.html.
Update its title, description, type, date, data-search keywords and link.
You can link to a PDF kept inside this website folder, a GitHub file,
a public Google Drive document, or a dedicated HTML article.

PUBLISHING
The site is static HTML/CSS/JavaScript and works with GitHub Pages,
Netlify, Cloudflare Pages and similar static hosts.
